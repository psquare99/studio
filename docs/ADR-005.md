ADR-005 — Blocks are Data, Definitions provide Behavior

Context

Studio is built around structured content blocks.

We need a way to support many different block types without coupling data to React components or editor logic.

Decision
Blocks are plain data.
Blocks never contain rendering logic.
Blocks never know how to publish themselves.
Blocks never know how to validate themselves.
Every block type has a Block Definition.
The editor discovers capabilities through Block Definitions.
Consequences
Documents remain portable.
React is isolated from the domain.
New block types can be added without modifying the editor.
Plugins become possible.
