ADR-003 — Documents are schema-driven
Context

Different kinds of content (journals, projects, documentation, tours, etc.) require different fields, but Studio should not have a separate editor for each content type.

Decision
Studio manages a single core entity: Document.
Every document has a unique identity.
Documents are independent of presentation.
A document's structure is defined by a Schema.
The editor renders fields based on the schema instead of hard-coded document types.
Publishing is handled by a separate service, not by the document itself.
Consequences
Adding a new content type requires defining a schema, not building a new editor.
Studio remains extensible.
The editor stays generic.
Websites consume structured documents rather than React components.
