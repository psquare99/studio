ADR-004 — Documents are composed of Metadata and Content Blocks
Context

Documents contain two fundamentally different kinds of information:

Structured facts (metadata)
Narrative content (blocks)

Mixing them together makes the editor harder to reason about.

Decision

A document consists of:

System Metadata
Schema Metadata
Content Blocks

A schema defines:

Metadata fields
Allowed block types
Validation rules
Default document template

The editor renders content blocks.

Metadata is edited separately.

Consequences
Metadata becomes searchable.
Content remains fluid.
New content types only require new schemas.
The editor stays generic.
